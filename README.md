# CAPSTONE PROJECT

## FastAPI CRUD API with SQLite

### 📌 About

A simple **Todo CRUD API** built using Python, FastAPI, SQLAlchemy, and SQLite.

### 🛠️ Technologies

* Python
* FastAPI
* SQLAlchemy
* SQLite
* Pydantic

### 🔄 CRUD Operations

* **POST** – Create a task
* **GET** – Read tasks
* **PUT** – Update a task
* **DELETE** – Delete a task

### 🗄️ Database

SQLite is used to store the tasks, while SQLAlchemy ORM connects Python with the database.

### ▶️ Run

```bash
uvicorn CRUD:app --reload
```

### 📖 API Documentation

Open:

```text
http://127.0.0.1:8000/docs
```

### 🎯 Objective

To understand and implement **FastAPI, CRUD operations, SQLite, SQLAlchemy ORM, and Pydantic validation**.
